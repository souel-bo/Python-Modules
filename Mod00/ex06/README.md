# Exercise 06 - Harvest Count

## Learning Objectives

- Learn repetition using loops.
- Understand recursion.
- Compare iterative and recursive solutions.

## Concepts Introduced

- `while`
- Recursion
- Base case
- Recursive call

## What is Required

Implement two functions:

```python
count_harvest_iterative()
```

and

```python
count_harvest_recursive()
```

Both should produce the same output.

## What You Need to Implement

### Iterative Version

- Read the number of days.
- Use a loop.
- Print every day.
- Print "Harvest time!".

### Recursive Version

- Read the number of days.
- Create a recursive function.
- Define a base case.
- Call the function recursively.
- Print "Harvest time!" after counting.

## Key Takeaways

- Loops repeat instructions.
- Recursion solves a problem by calling itself.
- Every recursive function needs a base case.
