# Exercise 00 - Hello Garden

## Learning Objectives

- Learn how to define a function in Python.
- Learn how to display text using `print()`.
- Understand the structure of a Python function.

## Concepts Introduced

- Function definition using `def`
- Function name
- Indentation
- Function body
- `print()`

## What is Required

Create a function named:

```python
hello_garden()
```

The function must print:

```
Hello, Garden Community!
```

Do not create a main program.

## What You Need to Implement

- Define a function.
- Use `print()`.
- Respect Python indentation.

## Key Takeaways

- Python uses `def` to define functions.
- Python uses indentation instead of braces.
- Functions execute only when called.
