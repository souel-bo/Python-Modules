# Exercise 03 - Harvest Total

## Learning Objectives

- Practice arithmetic operations.
- Work with multiple user inputs.
- Store intermediate results.

## Concepts Introduced

- Variables
- Integer addition
- Basic calculations

## What is Required

Read the required values.

Calculate the total harvest.

Display the final result.

## What You Need to Implement

- Read multiple values.
- Convert them to integers.
- Calculate the total.
- Print the answer.

## Key Takeaways

- Variables make calculations easier.
- Programs often follow:
  Input → Process → Output.
