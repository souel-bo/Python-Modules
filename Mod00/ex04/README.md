# Exercise 04 - Plant Age Check

## Learning Objectives

- Learn conditional execution.
- Make decisions inside programs.

## Concepts Introduced

- `if`
- `else`
- Comparison operators

## What is Required

Create:

```python
plant_age()
```

If age is greater than 60:

```
Plant is ready to harvest!
```

Otherwise:

```
Plant needs more time to grow.
```

## What You Need to Implement

- Read an integer.
- Compare its value.
- Execute different code depending on the result.

## Key Takeaways

- Programs can make decisions.
- Conditions evaluate to `True` or `False`.
- Python uses indentation for conditional blocks.
