# Exercise 01 - Garden Name

## Learning Objectives

- Learn how to receive input from the user.
- Store user input inside variables.
- Display variables using `print()`.

## Concepts Introduced

- `input()`
- Variables
- String values

## What is Required

Create a function:

```python
garden_name()
```

Ask the user for a garden name and display:

```
Garden: <name>
Status: Growing well!
```

## What You Need to Implement

- Read input using `input()`.
- Store the result.
- Print formatted messages.

## Key Takeaways

- `input()` always returns a string.
- Variables reference objects.
- User input can be reused later.
