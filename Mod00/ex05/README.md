# Exercise 05 - Water Reminder

## Learning Objectives

- Practice conditional logic.
- Combine multiple conditions.

## Concepts Introduced

- `if`
- `elif`
- `else`
- Logical thinking

## What is Required

Read the exercise statement.

Determine the correct reminder based on the given conditions.

Display the appropriate message.

## What You Need to Implement

- Evaluate multiple conditions.
- Choose the correct branch.
- Print the corresponding reminder.

## Key Takeaways

- `elif` allows testing multiple cases.
- Only one branch executes.
